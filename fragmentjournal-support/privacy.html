1. Data stored on your device / 端末内のデータ

Fragment Journal stores journal text, people, quotes, drafts, search data, and voice recordings locally on your device. The developer does not receive this content.

断片日記は、本文、人物、セリフ、下書き、検索用データ、音声を端末内に保存します。これらの内容を開発者が受信することはありません。

2. Permissions / 権限

Microphone access is requested only when you start recording. Optional App Lock uses iOS authentication; the app receives only whether authentication succeeded and does not receive biometric data.

マイク権限は録音開始時だけ求めます。任意のアプリロックはiOSの認証を使用し、アプリが受け取るのは認証結果のみで、生体情報を受け取りません。

3. Backup export and restore / バックアップ書き出しと復元

You can explicitly export a passphrase-protected encrypted backup through the iOS file interface. You can validate and restore a compatible backup by replacing the app’s current journal data. The app offers an option to export the current data before replacement. The developer does not receive the backup file or passphrase and cannot recover a lost passphrase.

iOSのファイル画面からパスフレーズ付き暗号化バックアップを書き出せます。対応するバックアップを検証し、現在の日記データを置き換えて復元できます。置き換え前に現在のデータを書き出す選択肢があります。開発者はバックアップファイルやパスフレーズを受信せず、紛失したパスフレーズを復元できません。

4. Purchases and RevenueCat / 購入とRevenueCat

Purchases are processed by Apple. Fragment Journal uses RevenueCat to load products, validate purchases, restore purchases, and maintain Pro entitlement state. RevenueCat may process an anonymous App User ID, device and platform technical information, and purchase transaction information for those purposes. The app does not send journal text, people, quotes, drafts, search data, voice recordings, backup files, or passphrases to RevenueCat.

購入はAppleが処理します。断片日記は、商品取得、購入確認、購入復元、Pro権利状態の維持にRevenueCatを使用します。そのためRevenueCatは、匿名のApp User ID、端末・プラットフォームの技術情報、購入取引情報を処理する場合があります。本文、人物、セリフ、下書き、検索用データ、音声、バックアップファイル、パスフレーズをRevenueCatへ送信することはありません。

5. Advertising and tracking / 広告とトラッキング

Fragment Journal contains no advertising and does not use data to track you across other companies’ apps or websites.

断片日記には広告がなく、他社のアプリやウェブサイトを横断して利用者を追跡しません。

6. Data deletion / データ削除

Entries can be moved to a 30-day trash and restored or permanently deleted. Uninstalling the app removes locally stored app data, subject to iOS backup behavior. Purchase records remain governed by Apple’s and RevenueCat’s retention policies.

記録は30日間のゴミ箱へ移動し、復元または完全削除できます。アプリ削除時は、iOSバックアップの挙動を除き端末内のアプリデータが削除されます。購入記録はAppleおよびRevenueCatの保持方針に従います。

7. Changes / 変更

Material changes will be posted on this page with an updated effective date.

重要な変更は、発効日を更新してこのページに掲載します。
