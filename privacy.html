2. Private Vault — current version / プライベート保管庫 — 現在のバージョン

Private Vault currently works on the user's iPhone only. It does not provide a developer-operated account, cloud storage, advertising, analytics, tracking, or purchases.

プライベート保管庫の現在のバージョンは、ユーザーのiPhone内だけで動作します。開発者が運営するアカウント、クラウド保管、広告、分析、トラッキング、購入機能はありません。

Information handled / 取り扱う情報

  • Photos and videos explicitly chosen with Apple's system picker; the app does not receive unrestricted access to the entire photo library. / Appleのシステム選択画面でユーザーが明示的に選んだ写真・動画。写真ライブラリ全体への無制限アクセスは取得しません。
  • Folder names, media-copy information, protection state, and app settings stored inside the app's protected area on the iPhone. / iPhone上のアプリ保護領域に保存されるフォルダ名、メディアコピー情報、保護状態、アプリ設定。
  • Per-item security credentials stored through the operating system's Keychain. / OSのKeychainを通じて保存される項目ごとのセキュリティ情報。
  • Vault file size and available-device-capacity values used only to display storage status on the device. / 端末上で保存状況を表示するためだけに使用する、保管庫ファイルサイズと端末の利用可能容量。

No developer-server transfer / 開発者サーバーへの送信なし

The current version does not transmit selected media, folder names, thumbnails, storage status, or usage events to the developer's server. The developer cannot remotely view or recover the user's media.

現在のバージョンは、選択したメディア、フォルダ名、サムネイル、保存状況、利用イベントを開発者サーバーへ送信しません。開発者がユーザーのメディアを遠隔で閲覧・復元することはできません。

Device authentication / 端末認証

Private Vault asks iOS to authenticate the device owner before showing private folders. The app receives only the authentication result and does not receive or store Face ID or other biometric data.

プライベート保管庫は、非公開フォルダを表示する前に端末所有者の認証をiOSへ依頼します。アプリが受け取るのは認証結果だけで、Face IDその他の生体情報を取得・保存しません。

Retention and deletion / 保存期間と削除

Because the current version has no developer server, the developer holds no remote copy to delete. Uninstalling the app removes its app container and locally stored media copies and folder information. Security credentials managed separately by the operating system may require separate handling after reinstall; contact support for current complete-deletion guidance. The current version does not delete the item in Apple's Photos app.

現在のバージョンには開発者サーバーがないため、開発者側に遠隔削除できるコピーはありません。アプリをアンインストールすると、アプリ領域内のメディアコピーとフォルダ情報は削除されます。OSが別に管理するセキュリティ情報は、再インストール後に別途対応が必要な場合があるため、完全削除の最新手順はサポートへお問い合わせください。現在のバージョンがAppleの写真アプリ内の項目を削除することはありません。

Planned space-saving viewing, cloud capacity, Pro subscriptions, and advertising are not active in the current version. This policy will be revised before any such feature is enabled. / 計画中の省スペース閲覧、クラウド容量、Proサブスクリプション、広告は現在有効ではありません。これらを有効化する前に本ポリシーを改訂します。

3. Soranji — version 1.2 / Soranji — バージョン1.2

This section applies specifically to Soranji version 1.2 and controls if it conflicts with the common provisions on this page.

本節はSoranjiバージョン1.2に固有の内容であり、本ページの共通規定と矛盾する場合は本節が優先されます。

Study content and on-device features / 学習内容と端末内機能

  • Study decks, answers, learning history, and app settings are stored in the app's local container. Version 1.2 has no developer-operated account, study-data cloud sync, or cloud-completion service. / 単語帳、回答、学習履歴、アプリ設定は、アプリのローカル領域に保存されます。バージョン1.2には、開発者運営のアカウント、学習データのクラウド同期、クラウド補完サービスはありません。
  • Photo-library and camera access occur only after the user chooses those actions for OCR. Apple Vision recognizes text on the device. Soranji reads the chosen image temporarily for recognition, does not upload it or save it in the study database, and saves only word pairs the user confirms. / 写真ライブラリとカメラへのアクセスは、ユーザーがOCRのためにその操作を選んだ場合だけ行われます。文字認識には端末内のApple Visionを使用します。Soranjiは選択画像を認識のため一時的に読み取りますが、アップロードしたり学習データベースへ保存したりせず、ユーザーが確定した単語ペアだけを保存します。

Advertising and consent / 広告と同意

Eligible Free users may see one Google AdMob native ad on a study-result screen after the first app session, with a limit of three impressions per day. Plus users do not receive ad requests. Soranji disables ad personalization at the publisher level, does not request the advertising identifier (IDFA), and does not show an App Tracking Transparency prompt.

対象となる無料ユーザーには、初回利用後の学習結果画面でGoogle AdMobのネイティブ広告が1枠表示される場合があり、表示は1日3回までです。Plusユーザーには広告をリクエストしません。Soranjiはパブリッシャー設定で広告のパーソナライズを無効化し、広告識別子（IDFA）を要求せず、App Tracking Transparencyの許可画面も表示しません。

Non-personalized treatment and the absence of an ATT prompt do not mean that the advertising SDK processes no data. Google states that the Mobile Ads SDK may process the following data for third-party advertising, analytics, diagnostics, fraud prevention, and service performance as applicable:

非パーソナライズ設定やATT画面を表示しないことは、広告SDKがデータをまったく処理しないことを意味しません。Googleは、Mobile Ads SDKが、該当する第三者広告、分析、診断、不正防止、サービス性能のために次のデータを処理する場合があると説明しています。

  • Internet Protocol (IP) address used to estimate general location / おおよその位置情報の推定に使用されるIPアドレス
  • Crash logs that are not user-related / ユーザーに関連付けられないクラッシュログ
  • User-associated performance data such as app launch time, hang rate, and energy use / 起動時間、ハング率、電力使用量等のユーザーに関連付けられるパフォーマンスデータ
  • An advertising or app/developer-bounded device identifier / 広告識別子またはアプリ・開発者に限定された端末識別子
  • Advertising data such as ads viewed / 表示した広告等の広告データ
  • Product-interaction data such as app launches, taps, and video views / アプリ起動、タップ、動画表示等の製品操作データ

Soranji uses Google's User Messaging Platform (UMP) to request and record privacy choices where required. If Google reports that privacy options are required, Soranji makes the privacy-options form available in the app. Google's determinations about its own processing and tracking may vary by region and configuration.

Soranjiは、必要な地域でプライバシー選択を求め、記録するためにGoogle User Messaging Platform（UMP）を使用します。Googleがプライバシーオプションを必要と判定した場合、Soranjiはアプリ内からその画面を利用できるようにします。Google自身の処理およびトラッキングに関する判定は、地域や設定によって異なる場合があります。

Purchases / 購入

Apple processes payment credentials. Soranji uses RevenueCat to verify and restore Plus entitlements. RevenueCat may process an anonymous app user identifier, device type and operating system, Apple receipt and transaction information, purchase history, last-use information, and entitlement status for those purposes. Soranji disables RevenueCat's automatic device-identifier collection.

支払い資格情報はAppleが処理します。SoranjiはPlus利用権の確認・復元にRevenueCatを使用します。そのためRevenueCatは、匿名のアプリユーザー識別子、端末種類とOS、Appleのレシートと取引情報、購入履歴、最終利用情報、利用権状態を処理する場合があります。SoranjiではRevenueCatによる端末識別子の自動収集を無効化しています。

Retention, deletion, and choices / 保存期間、削除、選択

Local study data remains until the user removes it in the app or uninstalls the app. Uninstalling removes the on-device app container; any device backup is controlled through Apple's services and settings. Advertising, consent, and purchase records controlled by Google, RevenueCat, or Apple are retained under each provider's terms. To request access to or deletion of information controlled by the developer or processed by RevenueCat on the developer's behalf, contact the developer below. Requests concerning data controlled directly by Google or Apple must use that provider's channel.

端末内の学習データは、ユーザーがアプリ内で削除するか、アプリをアンインストールするまで保持されます。アンインストールすると端末上のアプリ領域は削除されますが、端末バックアップはAppleのサービスと設定で管理されます。Google、RevenueCat、Appleが管理する広告、同意、購入の記録は、各事業者の条件に従って保持されます。開発者が管理する情報、または開発者の委託によりRevenueCatが処理する情報へのアクセス・削除を希望する場合は、下記の開発者へご連絡ください。GoogleまたはAppleが直接管理するデータについては、各事業者の窓口をご利用ください。

Provider information: Google Mobile Ads data disclosure · Google Privacy Policy · RevenueCat Privacy Policy · Apple Privacy Policy
