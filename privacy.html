2. Private Vault — current version / プライベート保管庫 — 現在のバージョン

Private Vault currently works on the user's iPhone only. It does not provide a developer-operated account, cloud storage, advertising, analytics, tracking, or purchases.

プライベート保管庫の現在のバージョンは、ユーザーのiPhone内だけで動作します。開発者が運営するアカウント、クラウド保管、広告、分析、トラッキング、購入機能はありません。

Information handled / 取り扱う情報

  • Photos and videos explicitly chosen with Apple's system picker; the app does not receive unrestricted access to the entire photo library. / Appleのシステム選択画面でユーザーが明示的に選んだ写真・動画。写真ライブラリ全体への無制限アクセスは取得しません。
  • Folder names, media-copy information, protection state, and app settings stored inside the app's protected area on the iPhone. / iPhone上のアプリ保護領域に保存されるフォルダ名、メディアコピー情報、保護状態、アプリ設定。
  • Per-item security credentials stored through the operating system's Keychain. / OSのKeychainを通じて保存される項目ごとのセキュリティ情報。
  • Vault file size and available-device-capacity values used only to display storage status on the device. / 端末上で保存状況を表示するためだけに使用する、保管庫ファイルサイズと端末の利用可能容量。

No developer-server transfer / 開発者サーバーへの送信なし

The current version does not transmit selected media, folder names, thumbnails, storage status, or usage events to the developer's server. The developer cannot remotely view or recover the user's media.

現在のバージョンは、選択したメディア、フォルダ名、サムネイル、保存状況、利用イベントを開発者サーバーへ送信しません。開発者がユーザーのメディアを遠隔で閲覧・復元することはできません。

Device authentication / 端末認証

Private Vault asks iOS to authenticate the device owner before showing private folders. The app receives only the authentication result and does not receive or store Face ID or other biometric data.

プライベート保管庫は、非公開フォルダを表示する前に端末所有者の認証をiOSへ依頼します。アプリが受け取るのは認証結果だけで、Face IDその他の生体情報を取得・保存しません。

Retention and deletion / 保存期間と削除

Because the current version has no developer server, the developer holds no remote copy to delete. Uninstalling the app removes its app container and locally stored media copies and folder information. Security credentials managed separately by the operating system may require separate handling after reinstall; contact support for current complete-deletion guidance. The current version does not delete the item in Apple's Photos app.

現在のバージョンには開発者サーバーがないため、開発者側に遠隔削除できるコピーはありません。アプリをアンインストールすると、アプリ領域内のメディアコピーとフォルダ情報は削除されます。OSが別に管理するセキュリティ情報は、再インストール後に別途対応が必要な場合があるため、完全削除の最新手順はサポートへお問い合わせください。現在のバージョンがAppleの写真アプリ内の項目を削除することはありません。

Planned space-saving viewing, cloud capacity, Pro subscriptions, and advertising are not active in the current version. This policy will be revised before any such feature is enabled. / 計画中の省スペース閲覧、クラウド容量、Proサブスクリプション、広告は現在有効ではありません。これらを有効化する前に本ポリシーを改訂します。

Information handled on the device / 端末内で取り扱う情報

Matters, in-progress drafts, answers, receipts, progress, and settings are stored in the app's local container. Tasuki does not create a developer-operated account, provide cloud sync, run analytics, track users, show ads, or send those entries to the developer.

Matter、作成途中の下書き、回答、受領記録、進捗、設定は、アプリのローカル領域に保存されます。Tasukiは、開発者運営のアカウントやクラウド同期を提供せず、分析、ユーザー追跡、広告表示を行わず、これらの入力内容を開発者へ送信しません。

Formal Matter data is eligible for the operating system's normal device-backup behavior. The separate in-progress Draft store is marked as excluded from backup. 確定したMatterデータは、OSの通常の端末バックアップの対象になり得ます。別に保存される作成途中の下書きは、バックアップ対象外として設定されています。バックアップの可否と復元は、Apple、端末、ユーザー設定により管理され、Tasukiはクラウド同期や端末間転送を保証しません。

アーカイブは元に戻すことができ、削除ではありません。ユーザーが完全削除を選ぶと、Tasukiは画面に示した短い取り消し猶予を設けます。猶予期間が過ぎると、選択した端末内の記録と関連する端末内記録が削除されます。アプリをアンインストールするとローカルのアプリ領域は削除されますが、Appleのサービスと設定で管理される端末バックアップが存在する場合があります。

あと箱は、箱の名前、文字1件または選択した写真1枚、手動で確定した取り出し・戻し時刻、訂正、アーカイブ状態、履歴、累計、設定をアプリのローカル領域に保存します。アプリ利用などの行動を自動検知するものではありません。

These services depend on the user's Apple Account, iCloud settings, available storage, network connection, and Apple's service availability. The developer does not operate a separate account or content server for the user's Nami journal.

気分記録、タグ、記録に必要な設定、月間の振り返りは、ユーザーのPrivate CloudKit databaseで同期される場合があります。任意の写真と音声は、ユーザーのPrivate iCloud Documents containerへコピーされる場合があります。これらはApple Account、iCloud設定、空き容量、通信、Appleのサービス状況に依存します。開発者はNamiの記録内容を保管する独自アカウントまたはコンテンツサーバーを運営しません。

HealthKit / HealthKit

HealthKit access is optional and read-only. When enabled, selected Health values are queried for on-device comparison with the user's mood records. Nami does not write Health data and does not add HealthKit-derived values to its CloudKit journal records. Health data is not provided by Nami to Google Mobile Ads or RevenueCat.

HealthKit連携は任意かつ読み取り専用です。有効にした場合、選択したHealth値を、本人の気分記録との端末内比較のために照会します。NamiはHealthデータを書き込まず、HealthKit由来の値をCloudKit上の記録へ追加しません。NamiからGoogle Mobile AdsまたはRevenueCatへHealthデータを提供しません。

Advertising, consent, and tracking / 広告、同意、トラッキング

The Free version may display a Google AdMob banner at the bottom of the Record tab. Nami uses Google's User Messaging Platform (UMP) to request and store privacy choices where required. The advertising SDK starts only after the consent flow reports that ads may be requested. Where applicable, iOS App Tracking Transparency permission may then be requested. Pro users do not receive this advertising placement.

Free版では、記録タブ下部にGoogle AdMobのバナー広告が表示される場合があります。Namiは、必要な地域でプライバシーの選択肢を提示・保存するためGoogle User Messaging Platform（UMP）を使用します。広告SDKは、同意フローが広告リクエスト可能と示した後に開始します。該当する場合、その後にiOSのApp Tracking Transparency許可を求める場合があります。Pro利用者にはこの広告枠を表示しません。

Google's SDKs may process data such as an IP-address-derived coarse location, device identifiers, advertising data, product interactions, performance data, crash data, and other diagnostics according to the user's region, choices, permissions, and Google's configuration. Nami does not send the user's mood score, tags, memo, photo, voice note, or HealthKit values to Google as ad-targeting fields.

GoogleのSDKは、地域、選択、許可、Google側設定に応じ、IPアドレスから推定した概算位置、端末識別子、広告データ、製品操作、パフォーマンス、クラッシュ、その他診断データを処理する場合があります。Namiは、気分スコア、タグ、メモ、写真、音声、HealthKit値を広告ターゲティング項目としてGoogleへ送信しません。

Apple processes payments. Nami uses RevenueCat to obtain product offerings, validate purchase status, restore purchases, and determine the Pro entitlement. RevenueCat receives purchase history and an anonymous app user identifier for app functionality and service analytics. Nami does not provide a name or email address to RevenueCat and does not use RevenueCat purchase history for cross-app advertising tracking. Current price, billing period, renewal terms, and any trial eligibility are shown by the in-app purchase screen before purchase.

支払いはAppleが処理します。Namiは商品情報の取得、購入状態の検証、購入復元、Pro利用権の判定にRevenueCatを使用します。RevenueCatは、機能提供とサービス分析のため購入履歴と匿名のapp user identifierを受け取ります。NamiはRevenueCatへ氏名やメールアドレスを提供せず、RevenueCatの購入履歴をアプリ横断の広告トラッキングに使用しません。現在の価格、期間、更新条件、Trial適格性は購入前のアプリ内購入画面に表示します。

Retention, deletion, and uninstalling / 保存、削除、アンインストール

In Settings, “Delete all personal data” deletes mood entries, memos, custom tags, monthly reflections, photos, and voice notes. When iCloud is connected, deletion is also synchronized to the related Private CloudKit and Private iCloud data. If an attachment cannot be removed from iCloud while offline or unavailable, Nami keeps a content-free deletion instruction and retries when iCloud becomes available. Apple purchase history remains associated with the Apple Account and is not removed by this action.

設定の「すべての個人データを削除」は、気分記録、メモ、カスタムタグ、月間の振り返り、写真、音声を削除します。iCloud接続中は、関連するPrivate CloudKitおよびPrivate iCloud側にも削除を同期します。オフラインまたはiCloudが利用できず添付を削除できない場合、Namiは内容を含まない削除指示を保持し、iCloud利用可能後に再試行します。Appleの購入履歴はApple Accountに残り、この操作では削除されません。

Uninstalling removes the app's local container but does not guarantee immediate deletion of data already synchronized to Private iCloud. To remove Nami data comprehensively, use the in-app delete-all action while iCloud is available before uninstalling. Provider-controlled advertising, consent, diagnostic, and purchase records follow Google, RevenueCat, and Apple's respective retention and request processes.

アンインストールは端末内のapp containerを削除しますが、Private iCloudへ同期済みのデータが直ちに削除されることを保証しません。Namiのデータを包括的に削除するには、アンインストール前にiCloudが利用可能な状態でアプリ内全削除を実行してください。Google、RevenueCat、Appleが管理する広告、同意、診断、購入記録には、各社の保存期間と請求手続が適用されます。
