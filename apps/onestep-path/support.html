Privacy / プライバシーTerms / 利用規約OneStep Path

OneStep Path turns each daily completion record into one visible step along a journey. It is designed to make long-term progress feel concrete without requiring an account or cloud service.

OneStep Pathは、1日の達成記録を道の「一歩」として可視化します。アカウントやクラウドサービスを必要とせず、長期的な進捗を手触りのある形で確認するためのアプリです。

FAQ / よくある質問

How do I add today's step? / 今日の一歩を記録するには？

Open the journey, tap the record button, add an optional memo, and save. The step is added only after saving succeeds.

道を開き、記録ボタンを押して、必要ならメモを入力し保存してください。保存に成功した場合だけ、一歩が追加されます。

Why can I not add another record today? / 今日もう1件記録できないのはなぜですか？

The current version permits at most one new record per local calendar day for each journey. Existing older data may contain two records on one day; OneStep Path preserves those historical records but does not allow an additional new record for that day.

現在のバージョンでは、各道につきローカル日付ごとに新規記録を1件まで追加できます。以前のデータに同じ日の記録が2件ある場合は過去記録として保持しますが、その日にさらに新しい記録を追加することはできません。

Can I edit a memo? / メモを編集できますか？

You can edit the memo attached to today's record. Older daily memos remain part of the journey history but are not editable in the current version.

今日の記録に付けたメモは編集できます。過去の日のメモは道の履歴として保持されますが、現在のバージョンでは編集できません。

How do I switch journeys? / 道を切り替えるには？

Use the journey selector at the top of the main screen and choose the journey you want to view. Settings and resets apply to the selected journey only.

メイン画面上部の道の選択ボタンから、表示したい道を選んでください。設定とリセットは選択した道だけに適用されます。

Where is my data stored? / データはどこに保存されますか？

Journey data and optional memos are stored in OneStep Path's local app container and app-only preferences on this iPhone. The current version has no developer-operated account or cloud synchronization and does not send journey content to a developer server.

道のデータと任意入力のメモは、このiPhone上のOneStep Path専用領域とアプリ専用設定に保存されます。現在のバージョンには開発者運営のアカウントやクラウド同期がなく、道の内容を開発者サーバーへ送信しません。

How do I delete records and memos? / 記録とメモを削除するには？

Open the selected journey's settings and use its reset control. After confirmation, the records and memos for that journey are removed and its start date is reset. Other journeys are not affected. Uninstalling OneStep Path removes its local app container, subject to Apple's backup behavior.

選択した道の設定を開き、リセット操作を使用してください。確認後、その道の記録とメモが削除され、開始日がリセットされます。ほかの道には影響しません。OneStep Pathをアンインストールすると、Appleのバックアップ動作を除き、端末内のアプリ専用領域が削除されます。

Does OneStep Path offer Pro or a subscription? / Proやサブスクリプションはありますか？

No active purchase product or subscription is offered in the current version. Any future purchase is available only after OneStep Path shows a real App Store purchase sheet with the current product, price, benefits, and terms.

現在のバージョンには、有効な購入商品やサブスクリプションはありません。将来購入を提供する場合は、現在の商品、価格、特典、条件を示す実際のApp Store購入画面が表示された後に限ります。
