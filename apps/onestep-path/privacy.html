OneStep Path Privacy Policy
プライバシーポリシー

Effective and last updated: July 22, 2026 / 施行・最終更新日: 2026年7月22日

Support / サポートTerms / 利用規約OneStep Path

Operator and data controller / 運営者・データ管理者: imai apps developer (Japan) / imai apps開発者（日本）

Contact / 連絡先: imai.issatsu@gmail.com

OneStep Path does not require an account and does not send journey records or optional memos to a developer-operated server.

OneStep Pathはアカウント登録を必要とせず、道の記録や任意入力のメモを開発者運営サーバーへ送信しません。

1. Scope / 適用範囲

This policy explains how the current version of OneStep Path handles information. Apple, GitHub Pages, and any website or service you open have their own privacy policies.

本ポリシーは、現在のOneStep Pathにおける情報の取り扱いを説明します。Apple、GitHub Pages、およびユーザーが開くウェブサイトやサービスには、それぞれのプライバシーポリシーが適用されます。

2. Data stored on the device / 端末内に保存するデータ

OneStep Path stores the following information in the app's local container and app-only preferences on the user's iPhone:

OneStep Pathは、以下の情報をユーザーのiPhone上にあるアプリ専用領域とアプリ専用設定へ保存します。

  • Journey goals, start dates, journey length, visualization choices, progress state, and milestone state / 道の目標、開始日、長さ、表示方法、進捗状態、節目の状態
  • Daily record dates and times, plus optional memo text entered by the user / 日々の記録日時と、ユーザーが任意で入力するメモ
  • Journey names, selected journey, and local app settings / 道の名前、選択中の道、端末内のアプリ設定

Depending on the user's device and Apple settings, app data may be included in a device or iCloud backup managed by Apple.

端末やAppleの設定によっては、Appleが管理する端末バックアップまたはiCloudバックアップにアプリデータが含まれる場合があります。

3. No developer-server collection / 開発者サーバーによる収集なし

The current version has no developer-operated account, cloud synchronization, analytics service, advertising SDK, tracking SDK, or active purchase system. Journey data and memo text are not transmitted to the developer, and the developer cannot remotely view or recover them.

現在のバージョンには、開発者運営アカウント、クラウド同期、分析サービス、広告SDK、トラッキングSDK、有効な購入システムはありません。道の記録やメモは開発者へ送信されず、開発者が遠隔で閲覧・復元することもできません。

4. Legal and support links / 法務・サポートリンク

When the user opens Privacy, Terms, or Support from the app, iOS opens the selected page hosted on GitHub Pages. Standard web-request information may be processed by Apple, the browser, GitHub, and their infrastructure under their own policies. OneStep Path does not add an account identifier or journey content to those links.

アプリからプライバシー、利用規約、サポートを開くと、iOSがGitHub Pages上の選択ページを開きます。通常のウェブアクセス情報は、Apple、ブラウザ、GitHubおよび各社の基盤により、それぞれのポリシーに基づいて処理される場合があります。OneStep Pathがアカウント識別子や道の内容をリンクへ追加することはありません。

5. Retention and deletion / 保存期間と削除

Journey data remains on the device until the user resets the relevant journey or removes the app. Resetting a journey removes its daily records and memos and restarts that journey without changing other journeys. Uninstalling OneStep Path removes its local app container, subject to Apple's backup and restoration behavior.

道のデータは、ユーザーが対象の道をリセットするか、アプリを削除するまで端末内に残ります。道をリセットすると、その道の日々の記録とメモが削除され、ほかの道には影響せず開始状態へ戻ります。OneStep Pathをアンインストールすると、Appleのバックアップと復元の動作を除き、端末内のアプリ専用領域が削除されます。

6. Security and permissions / 安全管理と権限

Data is stored inside the app's iOS container and app-only preferences. The current version does not request camera, microphone, photo-library, location, contacts, health, advertising-tracking, or notification permission.

データはiOSのアプリ専用領域とアプリ専用設定に保存されます。現在のバージョンは、カメラ、マイク、写真、位置情報、連絡先、ヘルスケア、広告トラッキング、通知の許可を求めません。

7. Children / 子どものプライバシー

OneStep Path is a general-audience productivity tool and is not directed specifically to children. Users below the minimum age for digital consent in their country or region should use it only with authorization from a parent or legal guardian.

OneStep Pathは一般向けの生産性ツールであり、子どもを主な対象としていません。国・地域で定められたデジタル同意の最低年齢に満たない方は、保護者または法定代理人の許可を得て利用してください。

8. Choices, rights, and complaints / ユーザーの選択・権利・苦情

The developer holds no remote copy of journey data or memos. Where applicable, users may contact the developer about privacy questions or rights. Requests concerning data controlled directly by Apple, GitHub, or another provider must be made to that provider.

開発者は道の記録やメモの遠隔コピーを保有しません。プライバシー上の質問や適用法上の権利については開発者へご連絡ください。Apple、GitHubその他の事業者が直接管理する情報については、その事業者へ請求してください。

9. Changes / 変更

This policy may be updated when OneStep Path's features, providers, or legal requirements change. Material changes will be reflected by updating the effective date on this page before the relevant feature is offered.

OneStep Pathの機能、利用する事業者、法的要件の変更に応じて本ポリシーを更新する場合があります。重要な変更は、関連機能の提供前に本ページの施行日を更新して反映します。
